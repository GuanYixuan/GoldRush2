# 中心区距离模型对照

本文记录中心区金币生成位置权重的距离模型对照。目标是判断中心区是否应使用逐格经验权重，还是可以用更鲁棒的径向距离函数近似。

## 数据与口径

数据来自两组已合并 replay 的 `cell_summary.csv`：

- 地图1：`symobs-a-map1-100-20260727-231446`
- 地图2：`symobs-a-map2-100-20260727-231704`

筛选条件：

- `region = 1`
- `static_map = 0`
- `exposure > 0`
- 排除 `(4,11)`，该格已确认为观测/站位干扰

坐标使用 replay 中的 0-based 坐标，中心点为 `(8,8)`。

使用 Poisson offset 模型拟合单格事件数：

```text
events[cell] ~ Poisson(exposure[cell] * rate[cell])
log(rate[cell]) = f(distance(cell))
```

这里的 `rate[cell]` 指单个中心区格子在一次 `end[t-1] -> start[t]` 回合转换中发生“新增金币事件”的触发率。由于同一格同一转换中目前只按一次正 delta 事件计数，且拟合出的单格概率最高约 `0.06`，后续生成器中可把它直接解释为每格每回合的 Bernoulli 触发概率；Poisson offset 只是用于聚合计数拟合的统计写法。

比较的距离定义：

```text
sq = (row - 8)^2 + (col - 8)^2
cheb = max(abs(row - 8), abs(col - 8))
manh = abs(row - 8) + abs(col - 8)
```

`linear` 表示 `log(rate) = a + b * distance`；`categorical` 表示每个距离桶单独一个参数。`cell_saturated` 是每个 cell 一个参数的上界模型，只用于衡量解释度，不作为生成模型。

合并口径使用地图独立截距、共享距离斜率或距离桶：

```text
log(rate) = a_map + f(distance)
```

## 模型对照

`LL gain` 是相对常数率模型的 log-likelihood 提升。`解释度` 是 `LL gain / cell_saturated LL gain`。`AIC delta` 是相对该组中最佳 AIC 的差值，越小越好。

合并拟合给出的中心区径向率可以写成：

```text
rate(row, col) = A_map * exp(-0.06735 * ((row - 8)^2 + (col - 8)^2))
```

其中当前两组数据的中心点基准率非常接近：

| 地图 | `A_map` |
| --- | ---: |
| 地图1 | `0.059621` |
| 地图2 | `0.059564` |

这表示平方欧氏距离每增加 `1`，事件率约乘以 `0.9349`。

## 独立触发检查

还需要区分两种可能解释：

1. 各中心格按自己的 `center_rate(row, col)` 近似独立触发。
2. 存在某种回合级开关或强全局因子，导致某些回合集中触发很多格，只是在长时间平均后看起来像逐格 rate。

为检查该点，按 `game_id, round` 聚合中心区正事件数，并与“当回合所有可见干净中心格按平方欧氏距离 rate 独立 Bernoulli 触发”的 Poisson-binomial 预测分布对照。

额外过滤：

- 排除 `(4,11)`。
- 排除 `window_begin = 0` 的初始窗口，避免初始地图金币污染。
- 每回合预测分布按该回合实际出现在 `cell_transitions.csv` 中的中心格集合计算，因此可见性差异已经条件化处理。

如果存在明显回合级 burst，观测分布应表现为零事件回合和高事件数回合同时偏多，方差显著高于独立 Bernoulli 预测。实际结果没有出现这种现象。

## 结论

中心区位置权重建议从逐格经验权重改为平方欧氏距离径向模型：

```text
center_rate(row, col) = A * exp(-0.06735 * ((row - 8)^2 + (col - 8)^2))
```

其中 `center_rate(row, col)` 的含义是：在该中心区非障碍格上，每个回合转换触发一次小额金币生成事件的概率。触发后金额分布另行建模，当前观察建议使用 `UniformInteger(1, 11)`，不要把 `center_rate` 理解为期望金币金额。

理由：

1. 排除 `(4,11)` 后，该模型在两张图上分别解释 `99.41%` 和 `99.69%` 的逐格上界 LL gain，合并后为 `99.56%`。
2. 它只需要一个距离斜率参数，AIC 优于逐格 saturated 模型，明显比 Chebyshev/Manhattan 更稳健。
3. 两张图拟合出的斜率几乎一致：`-0.067454` 与 `-0.067262`，说明该距离规律跨图稳定。
4. 每回合事件数分布与独立 Bernoulli 预测高度一致，未观察到明显回合级 burst。

后续生成器中可先固定斜率 `0.06735`，再用更多布局数据校准 `A`。若存在长期站位格或观测盲点，应在建模样本中排除，或额外乘以站位/可见性修正，不应让这些格子污染径向距离规律。
