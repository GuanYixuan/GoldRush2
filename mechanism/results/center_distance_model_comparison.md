# 中心区距离模型对照

本文记录中心区金币生成位置权重与独立触发假设的跨地图校验。结论基于地图1、地图2、地图3 M3-A/M3-B 双视角合并 replay 的离线特征表。

## 数据与口径

输入特征表：

```text
mechanism/data/processed/gold_features/<run_id>/cell_summary.csv
mechanism/data/processed/gold_features/<run_id>/cell_transitions.csv
```

使用的批次：

| 地图 | run_id | 对局数 |
| --- | --- | ---: |
| 地图1 | `symobs-a-map1-100-20260727-231446` | `100` |
| 地图2 | `symobs-a-map2-100-20260727-231704` | `100` |
| 地图3 M3-A | `symobs-m3a-map3-100-20260728-200953` | `100` |
| 地图3 M3-B | `symobs-m3b-map3-100-20260728-202647` | `100` |

筛选条件：

- `region = 1`
- `static_map = 0`
- `exposure > 0`
- 地图1/2 排除 `(4,11)`，该格已确认为观测/站位干扰
- 排除 `window_begin = 0` 的初始窗口做独立触发检查

坐标使用 replay 中的 0-based 坐标，中心点为 `(8,8)`。

拟合使用 Poisson offset 模型：

```text
events[cell] ~ Poisson(exposure[cell] * rate[cell])
log(rate[cell]) = f(distance(cell))
```

这里 `rate[cell]` 指单个中心区格子在一次 `end[t-1] -> start[t]` 回合转换中发生新增金币事件的触发率。由于单格概率最高约 `0.06`，后续生成器可直接把它解释为每格每回合 Bernoulli 触发概率；Poisson offset 只是聚合计数拟合写法。

比较的距离定义：

```text
sq = (row - 8)^2 + (col - 8)^2
cheb = max(abs(row - 8), abs(col - 8))
manh = abs(row - 8) + abs(col - 8)
```

地图3中心 `9x9` 内有较多静态障碍，且 M3-A/M3-B 都不覆盖 `(8,8)`，因此可用于中心拟合的普通格少于地图1/2。

参数形式：

```text
center_rate(row, col) = A * exp(-B * ((row - 8)^2 + (col - 8)^2))
```

地图1/2 的 `B` 约为 `0.06735`，地图3 pooled 为 `0.06260`，同量级且方向一致。第一版全图通用模型可以固定 `B ~= 0.065`，按地图或后续更多数据校准 `A`；若追求与地图1/2一致，也可继续使用 `B=0.06735`。

## 距离模型对照

`LL gain` 是相对常数率模型的 log-likelihood 提升；`解释度` 是相对于逐格 saturated 上界的解释比例；`AIC delta` 越小越好。

| 数据 | Cheb linear 解释度 | Manh linear 解释度 | sq linear 解释度 | sq linear AIC delta | saturated AIC delta |
| --- | ---: | ---: | ---: | ---: | ---: |
| 地图1 | `84.92%` | `89.45%` | `99.41%` | `0.000` | `20.393` |
| 地图2 | `84.20%` | `92.92%` | `99.69%` | `0.000` | `64.508` |
| 地图3 M3-A | `95.37%` | `84.61%` | `99.29%` | `0.000` | `10.309` |
| 地图3 M3-B | `94.36%` | `85.59%` | `99.08%` | `0.000` | `1.774` |
| 地图3 pooled | `94.82%` | `85.05%` | `99.13%` | `0.000` | `10.479` |

结论：平方欧氏距离的单斜率径向模型在所有地图上都接近逐格 saturated 上界，并稳定优于 Chebyshev / Manhattan linear。Chebyshev categorical 在地图3上也较强，但需要更多参数；第一版生成器仍应优先采用平方欧氏径向模型。

## 独立触发检查

为区分“逐格近似独立触发”和“某些回合集中爆发后长期平均成逐格 rate”，按 `game_id, round` 聚合中心区事件数，并与当回合可见中心格按径向 rate 独立 Bernoulli 触发的 Poisson-binomial 预测分布对照。

## 结论

中心区金币生成可建模为：

```text
for cell in center_9x9_non_obstacle:
    p = A * exp(-B * ((row - 8)^2 + (col - 8)^2))
    if Bernoulli(p):
        add UniformInteger(1, 11)
```

该结论由地图1/2/3共同支持：

1. 位置分布由平方欧氏距离解释，明显优于均匀分布和 Chebyshev/Manhattan linear。
2. 每回合事件数分布与独立 Bernoulli 预测高度一致，未观察到明显回合级 burst。
3. 触发后金额稳定近似 `UniformInteger(1, 11)`。
4. 站位或观测干扰格应在拟合样本中排除，或在生成器中作为额外可见性/站位修正处理。
