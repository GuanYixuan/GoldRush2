## 特征表口径

只把同一轮满足以下条件的 NPC 样本写入 round / step 明细：

- `start.npcs[id].position` 可见。
- `end.npcs[id].position` 可见。
- `end.npcs[id].actions` 存在。
- 用 `start_pos + actions` 重放后必须等于 `end_pos`，否则 fail-fast。

当前两图导出过程中未出现重放不一致，也未观察到 NPC 越界或撞静态障碍导致的非法移动。

`npc_interactions.csv` 中的 `bomb_trigger` 采用保守可见口径：

1. 从 `start.grid` 中所有可见炸弹开始。
2. 按 `end.dispatch_order` 先模拟快玩家，再模拟连续可见 NPC。
3. NPC 移动到仍存在的可见炸弹格时，记录 `bomb_trigger` 并移除该炸弹。
4. 不补全不可见炸弹，因此该表低估真实 NPC 炸弹触发次数。

## 炸弹避让信号

用 `npc_step_events.csv` 检查 NPC 第一步相对最近可见炸弹的距离变化。这里仍然只看可见炸弹。

合并结果：

| nearest bomb dist before | cases | closer | same | farther | target start bomb |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | `99273` | `2780` | `14561` | `81932` | `2780` |
| 2 | `184062` | `75972` | `23967` | `84123` | `0` |
| 3 | `168447` | `78799` | `26553` | `63095` | `0` |
| 4 | `118888` | `62264` | `20233` | `36391` | `0` |
| 5 | `64649` | `36674` | `10673` | `17302` | `0` |
| `>=6` | `48352` | `29477` | `6953` | `11922` | `0` |

最近可见炸弹距离为 `1` 时：

- 第一步直接踩向炸弹：`2.80%`
- 第一步保持同距离：`14.67%`
- 第一步远离炸弹：`82.53%`

作为对照，最近可见金币距离为 `1` 时：

- 第一步踩向金币：`48.68%`
- 第一步保持同距离：`18.76%`
- 第一步远离金币：`32.56%`

结论：

- NPC 对邻接炸弹存在非常强的避让信号。
- 该信号与邻接金币响应方向相反：NPC 会频繁走向邻接金币，但极少主动踩向邻接炸弹。
- 当最近炸弹距离大于 `1` 时，距离变化受路径目标、地图几何和金币吸引共同影响，不能简单解释为持续远离炸弹。

## 炸弹触发解释

所有 step 中，目标格在 `start.grid` 中为可见炸弹的样本共 `9165` 次；其中按调度重放后记录到 `bomb_trigger` 的为 `8560` 次：

```text
8560 / 9165 = 93.40%
```

未记录为触发的样本主要可能来自：

- 先手玩家已触发该炸弹。
- 更早行动的 NPC 已触发该炸弹。
- merged replay 的可见性边界导致局部状态不完整。

这说明 `bomb_trigger` 事件表与 step 目标格特征是相互一致的：NPC 走到可见且仍存在的炸弹格时，基本都会触发并移除炸弹。

## 建模建议更新

NPC 行为建模至少应包含以下特征：

- `step_idx`：三个 step 的动作分布不同。
- 局部金币特征：最近金币距离、目标格金币、半径 3 内金币总量。
- 局部炸弹特征：最近炸弹距离、目标格是否炸弹。
- 边界和静态障碍特征。
- 中心距离或 region。
- 调度上下文：快玩家已行动，NPC 内部顺序为随机 permutation。

第一版可从五动作 softmax 开始：

```text
score(action) =
    step_bias[step_idx, action]
  + gold_terms(action)
  + bomb_terms(action)
  + geometry_terms(action)
```

其中炸弹项应至少包含：

```text
if target_has_visible_bomb:
    large negative weight

if nearest_visible_bomb_dist_before == 1 and action moves farther:
    positive weight
```

但要避免把炸弹避让写成绝对规则：当前仍有 `8560` 次可见炸弹触发，说明 NPC 会在金币、路径或其它未建模因素作用下踩炸弹。

## 后续优先实验

1. 基于 `npc_step_events.csv` 拟合 step-index-aware baseline，与 uniform legal action 对照。
2. 加入金币特征，量化金币对动作选择的解释增益。
3. 加入炸弹特征，量化邻接炸弹避让对 loss / accuracy 的提升。
4. 如果 step 级 softmax 不足，再改为 3-step path-level 模型，因为 NPC 每轮总是生成长度 3 的动作序列。
