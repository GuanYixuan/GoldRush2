# NPC 走步数与 0 步行为分析

本文记录 NPC 一回合内实际走步数分布，以及 `actions=[4,4,4]` 的 0 步行为是否伴随特殊局面。目标是判断 `stay_count` 是否只是一个普通 path shape 特征，还是可以进一步拆成更强的规则先验。

## 数据范围

使用四组已导出的 NPC 特征表和 merged replay：

- `symobs-a-map1-100-20260727-231446`
- `symobs-a-map2-100-20260727-231704`
- `symobs-m3a-map3-100-20260728-200953`
- `symobs-m3b-map3-100-20260728-202647`

基础走步数分布直接来自：

```text
mechanism/data/processed/npc_features/<run_id>/npc_round_observations.csv
```

其中 `nonstay_actions` 与 `actual_moves` 在当前数据中完全一致，说明未观察到“非停动作但非法未移动”的 NPC 样本。

0 步局部条件使用 merged replay 回查 `round.merged.start.grid` 和静态地图。

## 0 步样本的邻域条件

所有 0 步样本均为：

```text
actions = [4,4,4]
```

合并 `4142` 条 0 步样本的局部条件：

| 条件 | count | 0步内占比 |
| --- | ---: | ---: |
| 所有合法相邻格都是可见炸弹 | `718` | `17.34%` |
| 没有可见安全相邻格 | `718` | `17.34%` |
| 最近可见炸弹距离为 1 | `1216` | `29.36%` |
| 起点格有金币 | `457` | `11.03%` |
| 邻接可见金币 | `847` | `20.45%` |

作为对照，非 0 步样本中：

| 条件 | count | 非0步内占比 |
| --- | ---: | ---: |
| 所有合法相邻格都是可见炸弹 | `15` | `0.001%` |
| 没有可见安全相邻格 | `52` | `0.004%` |
| 最近可见炸弹距离为 1 | `175347` | `13.74%` |

因此：

```text
P(0步 | 所有合法相邻格都是可见炸弹)
  = 718 / (718 + 15)
  = 97.95%
```

这说明“首步合法相邻格全是可见炸弹”是一个极强的 0 步触发条件，几乎可以单独作为规则例外或强先验。

| `symobs-a-map2-100-20260727-231704` | `3347` | `5` | `0.15%` |
| `symobs-m3a-map3-100-20260728-200953` | `231` | `231` | `100.00%` |
| `symobs-m3b-map3-100-20260728-202647` | `200` | `200` | `100.00%` |

map3 的 0 步基本全部由炸弹封住合法相邻格解释；map1 大部分也如此。map2 则明显存在另一类固定坐标停留现象。

```text

```

这些位置的静态局部结构多为障碍斜向夹角或区域边界附近，但不能仅由“周围都是炸弹”或“周围都是障碍”解释。当前不建议直接加入 per-cell 参数，因为这很容易过拟合 map2 和当前采集布局。

## 连续停留段

0 步常形成连续停留段，尤其是 map1/map3：

| run_id | zero count | zero streak count | 长度20 streak |
| --- | ---: | ---: | ---: |
| `symobs-a-map1-100-20260727-231446` | `364` | `88` | `12` |
| `symobs-a-map2-100-20260727-231704` | `3347` | `1437` | `0` |
| `symobs-m3a-map3-100-20260728-200953` | `231` | `15` | `10` |
| `symobs-m3b-map3-100-20260728-202647` | `200` | `16` | `8` |

map1/map3 中长度 20 的停留段与炸弹刷新周期一致，支持“被炸弹封住后直到炸弹刷新/消失前持续停留”的解释。map2 的停留段更分散，存在较多长度 `1..4` 和少量更长段，机制仍未完全解释。

## 建模建议

当前建议把 0 步行为拆成两层：

### 基础 shape 先验

仍保留 `stay_count` 强负权重，表达 NPC 通常走满 3 步：

```text
score(path) += w_stay * stay_count(path)
```

当前 M3c 拟合中：

```text
w_stay = -3.019169
```

### 炸弹封路例外

额外加入强规则或强特征：

```text
if all legal adjacent non-stay moves are visible bombs:
    strongly prefer [4,4,4]
```

实现上可以有两种方式：

1. 硬规则：该条件下直接选择 `[4,4,4]`，或以极高概率选择 `[4,4,4]`。
2. softmax 特征：给 `[4,4,4]` 增加 `bomb_trapped_stay_bonus`。

考虑到数据中仍有 `15` 条非 0 步样本满足该条件，更稳妥的是第二种：

```text
score(path) += w_bomb_trapped_stay * I(all_adjacent_legal_bombs and path == [4,4,4])
```

该项可作为 M4 的优先候选，比 region/per-cell 参数更稳健。

### 暂不建模 map2 固定坐标停留

map2 的固定坐标停留现象真实存在，但目前尚无足够证据说明它是官方 NPC 内置规则、地图几何效应、隐藏状态，还是采集布局造成的状态分布偏差。第一版模拟器不建议加入 per-cell 停留权重。

若后续 rollout 显示 map2 停留统计对训练重要，再考虑加入弱 geometry 特征，而不是直接写死坐标。
