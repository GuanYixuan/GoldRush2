# 对称观察 Probe

本目录存放主号与观测账号配合使用的对称观察策略。策略目标是尽快到达固定站位，并在之后每回合购买 `9x9` 视野，用于采集金币/炸弹生成数据。

## 策略特征

- 每回合固定返回 `vp=2`，申请 `9x9` 视野。
- 每名玩家的两个角色各走最多 3 步，返回 `k=3`、`order=0`。
- 首轮根据视野内静态障碍自动区分 `地图1` / `地图2`。
- 路径只考虑静态障碍，不考虑 NPC、金币、炸弹和敌方角色。
- 到达目标点后原地不动。
- 不读取环境变量，不访问平台，不打印日志。

## 布局版本

`layout_a.py` 使用主布局：

```text
A = {(4,3), (4,11), (12,13), (13,4)}
```

`layout_ca.py` 使用中心镜像布局：

```text
C(A) = {(12,13), (12,5), (4,3), (3,12)}
```

两种布局的具体设计和对称性验证见：

```text
mechanism/symmetry_observation_plan.md
```

## 使用约束

任何平台提交、发起对局或观测账号数据拉取都必须另行获得明确授权。本目录只提供策略源码。
